# Use-Case Prioritization

## Scoring Methodology

Scores use a 1-5 scale for:
- Business Value
- Technical Complexity
- Data Engineering Depth
- AI/ML Depth
- Cloud/Platform Depth
- DevOps/MLOps Depth
- Security Depth
- Interview Value
- Real-World Relevance

Tiering:
- Tier 1: 35+
- Tier 2: 25-34
- Tier 3: below 25

## Selection Rationale

Tier 1 favors use cases that combine:
- enterprise data depth
- model lifecycle complexity
- strong security and compliance needs
- clear business value
- strong interview narrative potential

## Technology Distribution

Tier 1 heavily exercises:
- AWS
- Terraform
- Python
- SQL
- MLflow / registry patterns
- streaming and batch pipelines
- security and observability
