## ✨ Key Features

### Source of Truth
Everything in this repository is your authoritative professional knowledge. Copilot will use it as the baseline for all career advice, CV generation, and interview coaching.

### Evidence-Based
Every claim is backed by documentation. Skills have projects. Projects have metrics. Achievements have business impact. This prevents false claims and exaggeration.

### Confidentiality-Aware
Built with confidentiality guidelines. Client names are anonymised. Secrets are excluded. Classified content is clearly marked.

### AI-Integrated
GitHub Copilot reads `.github/copilot-instructions.md`. It knows:
- Never to fabricate experience
- To cite sources
- To respect confidentiality levels
- To prioritize evidence
- To flag gaps rather than assume

### Connected Knowledge Graph
Through relative Markdown links, your repository becomes a connected graph:
- Projects link to skills
- Skills link to achievements
- Achievements link to projects
- Everything is cross-referenced

### Interview-Ready
Automatically supports:
- Interview coaching based on actual projects
- STAR story preparation
- Mock interviews
- Question preparation by technology
- Gap analysis vs. target roles

### CV Generation
One-click CV generation:
1. Provide job description to Copilot
2. Copilot searches this repository
3. CV is generated with evidence-backed bullets
4. Gaps are identified

## ⚠️ Important Notes

### No Fabrication
This repository works only if it's accurate. The moment you invent projects or exaggerate skills, the entire system fails because Copilot will generate CVs with false claims.

### Build Gradually
Don't try to populate everything at once. Build knowledge over time. Each project adds to your repository. Each achievement adds evidence.

### Keep Current
Quarterly reviews ensure your professional knowledge stays current. Archive old technologies. Update classifications as you grow.

### Confidentiality
Remember: This is a Git repository. Review confidentiality before committing. Use anonymisation. Treat it like you'd treat anything that could be seen by competitors or future employers.
